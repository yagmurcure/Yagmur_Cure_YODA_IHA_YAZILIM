### Python Diline Giriş
##### Veri Tipleri
**String:**

- Metinsel ifadeleri tutmak için kullanılır. Tek tırnak ('...'), çift tırnak ("...") veya üç tırnak ("""...""") ile tanımlanır. Immutable yapıdadır.
- Stringler her karakterin ayrı bir eleman/değer gibi davrandığı diziler gibidir. metin[0] ilk karakteri, metin[5] 5. indeksteki karakteri verir.
- Stringler karakter dizisi mantığında olduğu için for x in metin: yapısıyla karakterler üzerinde tek tek dolaşılabilir ve her karakter (boşluklar dahil) sırayla işlenip yazdırılabilir.
- **len():** Bir stringin karakter sayısını öğrenmek için kullanılır.
- **in:** Aranan bir kelime veya karakterin string içinde var olup olmadığını kontrol eder. Varsa True, yoksa False döndürür.
- **not in:** Aranan ifadenin string içinde yok olup olmadığını kontrol eder. Yoksa True, varsa False döndürür.
- **İndeks aralığı:** Bir stringin belirli bir kısmını almak için köşeli parantez içinde [baslangic:bitis] şeklinde indeks aralıkları kullanılır.
- **+ operatörü:** İki veya daha fazla stringi birleştirmek için kullanılır. Sonuç yeni bir değişkene atanabilir veya doğrudan print() içinde yazdırılabilir.
- **.upper():** Bir stringdeki tüm harfleri büyük harfe çevirir.
- **.lower():** Bir stringdeki tüm harfleri küçük harfe çevirir.
- **.strip():** Stringin başındaki ve sonundaki boşlukları temizler.
- **.replace(eski, yeni):** String içinde belirtilen karakteri veya ifadeyi verilen yeni değerle değiştirir.
- **.split(ayirici):** Metni belirtilen karaktere göre parçalara ayırır ve sonucu bir liste olarak döndürür.
- **str():** Sayısal değişkenler, doğrudan + operatörüyle bir string ifadeye eklenemez, bu durumda TypeError hatası alınır. Birleştirme yapabilmek için ya sayının str() fonksiyonu ile metne dönüştürülmesi ya da string formatlama yöntemlerinin kullanılması gerekir.
- **.format() ve f-string:** .format() metodunda süslü parantez yer tutucularına değerler sırayla veya indeksle aktarılırken, f-string (f"...") yapısında değişkenler doğrudan {degisken} şeklinde metnin içine yazılır.
- **input():** Kullanıcıdan klavye aracılığıyla veri almak için kullanılır ve girilen her değeri her zaman str tipinde döndürür. Sayısal işlem yapılacaksa int() veya float() ile dönüştürülmelidir.
- **capitalize():** Stringin yalnızca ilk karakterini büyük harfe dönüştürür.
- **title():** Metindeki her kelimenin ilk harfini büyük yapar.
- **swapcase():** Stringdeki büyük harfleri küçük harfe, küçük harfleri ise büyük harfe dönüştürür.
- **islower():** Tüm karakterler küçük harf ise True, değilse False döndürür.
- **isupper():** Tüm karakterlerin büyük harf olup olmadığını kontrol ederek True veya False döndürür.
- **count(value, start, end):** Aranan bir değerin string içinde kaç kez geçtiğini sayar. İsteğe bağlı olarak başlangıç ve bitiş indeks aralığı verilebilir.
- **startswith() ve endswith():** Stringin belirtilen ifadeyle başlayıp başlamadığını kontrol eder ve True/False döndürür. Başlangıç/bitiş indeksi parametreleri de alabilir.
- **find() ve index():** Belirtilen değeri string içinde arar ve ilk bulunduğu indeks numarasını döndürür (başlangıç/bitiş aralığı da verilebilir). Değer bulunamazsa find() -1 döndürürken, index() ValueError / substring not found hatası verir.

Aşağıdaki kod bloğunda üstte yazdığım metodları içeren örnekler bulunmaktadır. Bunların dışında çok fazla string metodu var fakat hepsini buraya not etmenin gereksiz olacağını düşündüm.

```python
isim = "Yağmur"
mesaj = 'Python öğreniyorum'

# in ve not in kullanimi
if "öğreniyorum" in mesaj: # True donecegi icin icerisi calisir
    print("öğreniyorum mevuct") # Çıktı: öğreniyorum mevuct
if "yağmur" not in isim:   # case-sensitive oldugu icin bu da True doner
    print("yanlis yazdın") # Çıktı: yanlis yazdın

# uzunluk, indeksleme, dilimleme ve birlestirme
print(len(isim))            # Çıktı: 6
print(isim[0])              # Çıktı: Y
print(isim[1:4])            # Çıktı: ağm (1 dahil, 4 dahil degil)
print(mesaj[-4:])           # Çıktı: orum (sondan son 4 karakteri alir)
print(isim + " - " + mesaj) # Çıktı: Yağmur - Python öğreniyorum

# sik kullanilan string metodlari
text = "Çok Sıkıldım"
print(text.upper()) # Çıktı: ÇOK SIKILDIM
print(text.lower()) # Çıktı: çok sıkıldım

text2= "    baya sıkıldım  "
print(text2.strip())                   # Çıktı: baya sıkıldım (bas ve sondaki bosluklari siler)
print(text.replace("Çok","Çok fazla")) # Çıktı: Çok fazla Sıkıldım

text3="Selam-Merhaba-Naber"
print(text3.split("-")) # Çıktı: ['Selam', 'Merhaba', 'Naber']

# input ve string formatlama (ornek olarak 20 girildigini dusunelim)
yas = int(input("Yaşınızı girin: "))
print("Adım {}, yaşım {}".format(isim, yas)) # Çıktı: Adım Yağmur, yaşım 20
print(f"Adım {isim}, yaşım {yas}")           # Çıktı: Adım Yağmur, yaşım 20
```

**Listeler**
- Verileri sıralı bir şekilde bellekte tutmaya yarayan temel bir veri yapısıdır. Köşeli parantez ile oluşturulur ve elemanlar virgülle ayrılır.
- **len()** Listedeki toplam eleman sayısını döndürür.
- liste[indeks] ile istenen elemana ulaşılır. Olmayan bir indekse erişmeye çalışıldığında IndexError hatası alınır.
- **append()** listenin en sonuna tek bir eleman ekler; başka bir liste verilirse o listeyi tek bir alt liste elemanı olarak sona ekler.
- **insert(indeks, eleman)** belirtilen indeks konumuna eleman ekler ve o indeksteki ve sonrasındaki elemanları birer sağa kaydırır.
- **remove(deger)** Listede verilen değere sahip elemanı bulup listeden siler.
- **pop()** Listenin en sonundaki elemanı siler ve sildiği bu değeri geri döndürür (istenirse bir değişkene atanabilir).
- **reverse()** Listenin eleman sıralamasını doğrudan tersine çevirir ve orijinal listeyi günceller.
- **.sort()** metodu listeyi yerinde (metinlerde alfabetik, sayılarda küçükten büyüğe) sıralar ve orijinal listeyi değiştirir; reverse=True parametresiyle tersten sıralama yapılabilir. **sorted(liste)** fonksiyonu ise orijinal listeyi bozmadan sıralanmış yeni bir liste döndürür.
- **min()** en küçük (veya alfabetik olarak ilk) elemanı, **max()** en büyük (veya alfabetik olarak en sondaki) elemanı döndürür. **sum()** sayısal listelerdeki elemanların toplamını hesaplar, string listelerde TypeError hatası verir.
- **.extend(liste2)** başka bir listenin elemanlarını tek tek mevcut listenin sonuna ekler
- **ayirici.join(liste)** ile string elemanlı bir liste, araya belirtilen ayırıcı konularak tek bir str haline getirilir.

Üstte verilen metodların bazılarının örnekleri aşağıda kod bloğu içerisinde verilmiştir.

``` python
renkler = ["Siyah", "Beyaz", "Sarı", "Mavi", "Yeşil"]
print(len(renkler)) #5
renkler.append("Gri")
print(renkler)  # ['Siyah', 'Beyaz', 'Sarı', 'Mavi', 'Yeşil', 'Gri']
renkler.insert(2, "Pembe")
print(renkler)  #['Siyah', 'Beyaz', 'Pembe','Sarı', 'Mavi', 'Yeşil', 'Gri']
renkler.remove("Sarı")
print(renkler)  #['Siyah', 'Beyaz', 'Pembe', 'Mavi', 'Yeşil', 'Gri']
silinen = renkler.pop()
print(renkler)  #['Siyah', 'Beyaz', 'Pembe', 'Mavi', 'Yeşil']
print(silinen)  #Gri
stringrenkler = " - ".join(renkler)
print(type(stringrenkler))  # <class 'str'>
```

``` python
demet = ("Sarı", "Mavi", "Yeşil", "Kırmızı", "Siyah")
```

**Set**
- Süslü parantez içinde virgülle ayrılmış elemanlarla tanımlanır. Listeler ve demetlerden farklı olarak sırasızdır, her çalıştırmada farklı sırada görünebilir ve her elemandan yalnızca bir tane barındırır.
- **.add():** Kümeler sıralı olmadığı için sona ekleme mantığı yoktur; yeni eleman eklemek için kullanılır.
- **.remove() ve .discard():** Kümeden eleman silmek için kullanılır; aralarındaki fark, silinmek istenen eleman kümede yoksa .remove() KeyError hatası verirken .discard() hata vermeden çalışmaya devam etmesidir.
- **.intersection(), .union() ve .difference():** .intersection() iki kümenin kesişimini, .union() birleşimini ve .difference() ilk kümede olup ikinci kümede olmayan elemanları (fark kümesini) döndürür.

```python
kume1 = {"Sarı", "Mavi", "Yeşil", "Kırmızı", "Siyah"}
kume1.add("Pembe")
kume1.remove("Sarı")
kume1.discard("Gri")   # Kümede olmasa da hata vermez
kume1.discard("Mavi")  # Kümeden siler
kume2 = {"Sarı", "Mavi", "Yeşil", "Beyaz", "Gri"}
print(kume1.intersection(kume2))  # Kesişim
print(kume1.union(kume2))         # Birleşim
print(kume1.difference(kume2))    # kume1 - kume2
print(kume2.difference(kume1))    # kume2 - kume1
```

**Bool**

* Bir durumun doğru veya yanlış, var veya yok, aktif veya pasif olduğunu temsil eden mantıksal veri türüdür. Yalnızca True ve False değerlerini alır.
* Karşılaştırma işlemlerinin sonucu her zaman True veya False döner. En yaygın kullanım alanı if-else koşullu ifadeleridir.
* bool() Herhangi bir veriyi boolean değere dönüştürmek için kullanılır. Boş olmayan stringler, 0 dışındaki tüm sayılar ve içi dolu liste/demet gibi yapılar True döndürür.
* Boş string (""), 0 sayısı, False, None ve içi boş veri yapıları ([], (), {}) bool() içine verildiğinde False döndürür.
* Kendi yazdığımız fonksiyonlar return ile True veya False döndürerek koşullu ifadelerde kullanılabilir. Ayrıca isinstance(deger, tip) gibi Python'ın hazır bazı fonksiyonları da kontrol sonucunu doğrudan bool olarak döndürür.

```python
print(7 > 4)   # Çıktı: True
print(7 == 5)  # Çıktı: False

# bool() ile tur donusumu
print(bool("Python"))     # Çıktı: True
print(bool(19))           # Çıktı: True
print(bool([1, 2]))       # Çıktı: True
print(bool(""))           # Çıktı: False
print(bool(0))            # Çıktı: False
print(bool(None))         # Çıktı: False
print(bool([]), bool(()), bool({})) # Çıktı: False False False

# fonksiyonla bool dondurme ve if icinde kullanma
def aktif_mi():
    return True

if aktif_mi():
    print("Yes") # True dondugu icin bu calisir Çıktı: Yes
else:
    print("No")

# hazir fonksiyonlarin bool dondurmesi
x = 7
print(isinstance(x, int)) # Çıktı: True 
print(isinstance(x, str)) # Çıktı: False
```
**Dictionary**
* Verileri key-value çiftleri halinde tutan veri yapısıdır. Süslü parantez {} içinde anahtar: değer şeklinde tanımlanır ve elemanlar virgülle ayrılır.
* Anahtarlar string veya integer olmak zorundadır, değerler ise string, integer, liste, küme gibi herhangi bir veri tipi olabilir.
* Sözlüklerde liste gibi indeks numarası yoktur; bir veriye ulaşmak için köşeli parantez içine anahtar adı yazılır (sozluk["anahtar"]). Olmayan bir anahtara bu şekilde erişilmeye çalışılırsa KeyError hatası alınır.
* **Veri güncelleme ve ekleme:** sozluk["anahtar"] = deger şeklinde atama yapıldığında anahtar sözlükte varsa değeri güncellenir yoksa sözlüğe yeni bir anahtar-değer çifti olarak eklenir.
* **.update():** Aynı anda birden fazla alanı güncellemek için kullanılır, içine güncellenecek alanları barındıran yeni bir sözlük alır.
* **del:** Sözlükten belirtilen anahtarı ve ona karşılık gelen değeri silmek için kullanılır (del sozluk["anahtar"]).
* **.keys(), .values() ve .items():** .keys() yalnızca anahtarları, .values() yalnızca değerleri, .items() ise anahtar-değer çiftlerini ikili halde döndürür.
* **for döngüsü ile kullanım:** Sözlük üzerinde doğrudan for x in sozluk: ile dönüldüğünde x sırayla anahtarları alır, değerlere ulaşmak için sozluk[x] kullanılır. Hem anahtarı hem değeri birlikte almak için for k, v in sozluk.items(): yapısı kullanılır.
* **.get():** Bir anahtarın değerini hata almadan okumak için kullanılır. Aranan anahtar sözlükte yoksa KeyError vermek yerine None döndürür.

```python
kisi = {"isim": "Ali", "yas": 20, "hobiler": ["Sinema", "Yazılım"]}
# anahtar ile veriye erisme
print(kisi["isim"])        # Çıktı: Ali

# tek alan guncelleme ve yeni alan ekleme
kisi["isim"] = "Ahmet"     # var olan anahtari guncelledi
kisi["id"] = 12345         # olmayan anahtari yeni ekledi

# birden fazla alani tek seferde guncelleme
kisi.update({"isim": "Veli", "yas": 25})
print(kisi) # Çıktı: {'isim': 'Veli', 'yas': 25, 'hobiler': ['Sinema', 'Yazılım'], 'id': 12345}

# silme islemi
del kisi["id"]

# keys, values, items
print(kisi.keys())   # Çıktı: dict_keys(['isim', 'yas', 'hobiler'])
print(kisi.values()) # Çıktı: dict_values(['Veli', 25, ['Sinema', 'Yazılım']])

# for ile anahtar ve degerleri beraber yazdirma
for k, v in kisi.items():
    print(k, v) # alt alta: isim Veli, yas 25, hobiler ['Sinema', 'Yazılım']

# get() ile guvenli erisim 
print(kisi.get("id"))               # Çıktı: None
print(kisi.get("id", "Bulunamadi")) # Çıktı: Bulunamadi
```

##### Conditionals
**if**
- Belirli bir koşulun doğru olması durumunda altındaki girintili kod bloğunu çalıştıran kontrol yapısıdır. Koşul yanlış ise blok atlanır ve program devam eder.
**elif**
- İlk if koşulu yanlış olduğunda ek koşulları sırayla kontrol etmek için kullanılır.
**else**
- if koşulu sağlanmadığında çalışacak alternatif kod bloğunu tanımlar. Yanına koşul yazılmaz ve önceki koşullar yanlışsa devreye girer.
**is ve id()**
- == değer eşitliğine bakarken, is iki değişkenin bellekte aynı nesneyi işaret edip etmediğini (özdeşliğini) kontrol eder; id() fonksiyonu nesnenin bellek kimliğini/adresini gösterir.

```python
not_ort = 78

if not_ort >= 85:   # false odlugu icin calismadi
    print("AA aldik")
elif not_ort >= 70:
    print("Gectik") # Çıktı: Gectik
else:
    print("Kaldi") # bu calismadi cunku ustteki kosul tuttu

# == degerlere bakar is bellekte ayni yer mi diye bakar
a = [1, 2]
b = [1, 2]
c = a
print(a == b)          # Çıktı: True (icerikleri ayni)
print(a is b)          # Çıktı: False (iki ayri liste id'leri farkli)
print(a is c)          # Çıktı: True (c de a'nin gosterdigi listeyi gosteriyor)
print(id(a), id(b))    # Çıktı: (farkli iki sayi)
```
##### Döngüler

**for**
* Bir liste, demet veya string içindeki tüm elemanlar üzerinde sırayla aynı işlemi tekrarlamak için kullanılır. 
* for satırının sonuna : konulur ve döngünün içindeki kodlar bir tab içeride yazılır.
* **range() fonksiyonu:** Belirli iki sayı arasındaki tam sayıları üretir ve bir işlemi istenen sayıda tekrarlatmak için for ile sıkça kullanılır. İlk sınır dahildir, son sınır dahil değildir. Tek değer yazılırsa 0'dan başlar, üçüncü bir değer eklenirse artış miktarını belirler.
* **continue:** Belirli bir koşul sağlandığında döngünün o adımındaki kalan satırları atlar ve doğrudan bir sonraki adıma geçer (döngüyü bitirmez, sadece o elemanı pas geçer).
* **break:** Koşul sağlandığında döngüyü tamamen sonlandırır ve döngüden çıkar.

**while Döngüsü**
* Belirli bir koşul doğru olduğu sürece çalışmaya devam eden döngüdür. Koşul bozulduğunda döngü biter.
* while True: şeklinde sonsuz döngü oluşturulabilir; ancak bu kullanımda döngüyü durduracak bir break koşulu mutlaka yazılmalıdır. Ayrıca sayaç değişkenini (i += 1 gibi) artırmayı unutmamak gerekir, yoksa program kısır döngüye girer.

```python
# liste uzerinde for dongusu
liste = [1, 2, 3]
for sayi in liste:
    print(sayi) # alt alta 1, 2, 3 yazar
# range kullanimi
for i in range(1, 7, 2): # 1'den 7'ye kadar 2'ser artar
    print(i) # alt alta 1, 3, 5 yazar
# ic ice for dongusu
harfler = ["a", "b"]
rakamlar = [1, 2]
for h in harfler:
    for r in rakamlar:
        print(h, r) # sirayla: a 1, a 2, b 1, b 2 yazar

# break ve continue ornegi
for i in range(1, 6):
    if i == 2:
        continue # 2'yi pas gecer, alt satira inmez
    if i == 5:
        break # 5'i gorunce donguden tamamen cikar
    print(i) # Çıktı: alt alta 1, 3, 4

# while dongusu
x = 1
while x < 4:
    print(x) # alt alta 1, 2, 3 yazar
    x += 1   # bunu artirmazsak sonsuz donguye girer

# while True ile kontrollu cikis
i = 1
while True:
    if i == 3:
        break # 3 olunca donguyu bitirir
    print(i)  # alt alta 1, 2 yazar
    i += 1
```

##### Fonksiyonlar
* Tekrar tekrar kullanılacak kod bloklarını tek bir yerde toplayıp gerektiğinde çağırmak için kullanılır. Kod tekrarını önler ve bir değişiklik gerektiğinde her yeri tek tek düzeltmek yerine sadece fonksiyonun içini değiştirmek yeterli olur.
* Fonksiyon tanımlarken def anahtar kelimesi yazılır, ardından fonksiyonun adı, parantez () ve iki nokta konulur. Fonksiyonun yapacağı işlemler alt satırda girintili yazılır.
* Tanımlanan fonksiyonu çalıştırmak için adının sonuna parantez koyarak çağırmak gerekir, sadece adını yazmak fonksiyonu çalıştırmaz.
* Fonksiyonlar hiç parametre almadan tanımlanabileceği gibi dışarıdan bir veya birden fazla değer alacak şekilde de tanımlanabilir. Çağrılırken beklenen parametre sayısına ve türüne uygun değer gönderilmezse hata alınır.
* Parametre tanımlanırken eşittir ile varsayılan bir değer atanabilir. Fonksiyon çağrılırken o parametre girilmezse hata vermez ve varsayılan değeri kullanır, yeni değer girilirse onu kullanır.
* Fonksiyon içinde sadece print kullanıldığında sonuç yalnızca ekrana yazılır, bir değişkene atanmaya çalışılırsa None döner. return anahtar kelimesi ise sonucu geri döndürür, böylece dönen değer bir değişkene atanıp başka işlemlerde kullanılabilir.
* Fonksiyonlar da parantez kullanmadan başka bir değişkene eşitlenebilir ve o değişken adı üzerinden çağrılabilir.

```python
# parametresiz fonksiyon
def bilgi_ver():
    print("Islem basarili")
bilgi_ver() # Çıktı: Islem basarili

# parametre alan ve varsayilan degerli fonksiyon
def selamla(mesaj, isim="Anonim"):
    print(f"{mesaj} {isim}")
selamla("Merhaba", "Ahmet") # Çıktı: Merhaba Ahmet
selamla("Merhaba")          # isim girmedigimiz icin varsayilani alir "Merhaba Anonim"

# return kullanimi
def ortalama_hesapla(x, y):
    return (x + y) / 2
a = ortalama_hesapla(2, 6)  # 4.0 doner
b = ortalama_hesapla(6, 10) # 8.0 doner
```

##### Class

**Class Variables ve Instance Variables**
* Instance variables, `__init__` fonksiyonu içinde self ile tanımlanan ve sınıftan üretilen her nesnede farklı değer alabilen değişkenlerdir.
* Class variables , sınıfın içinde doğrudan tanımlanan ve o sınıftan üretilen tüm nesneler için ortak olan değişkenlerdir.
* Bir nesnenin veya sınıfın sahip olduğu özellikleri sözlük şeklinde görmek için `.__dict__` kullanılır.
* Sınıf değişkenlerine hem sınıf adı üzerinden hem de üretilen nesneler üzerinden erişilebilir. Nesne üzerinden bir değişkene erişilmek istendiğinde Python önce nesnenin kendisine bakar, orada bulamazsa sınıfın içine bakar.
* Bir sınıf değişkeni sınıf adı üzerinden güncellenirse tüm nesneleri etkiler. Ancak bir nesne üzerinden güncellenirse sadece o nesneye yeni bir özellik eklenmiş gibi davranır ve diğer nesneler bundan etkilenmez.
* Her nesne oluşturulduğunda `__init__` otomatik çalıştığı için, tüm nesneleri sayan ortak bir sayaç yapmak istediğimizde değişkeni self ile değil sınıf adı üzerinden artırmak gerekir. self kullanılırsa sadece o nesneye ait ayrı bir değişken gibi davranır.

**Instance Methods, Class Methods ve Static Methods**
* Instance method, sınıf içinde herhangi bir dekoratör kullanmadan doğrudan def ile tanımlanan metotlardır ve ilk parametre olarak otomatik self alır.
* Instance metotlar oluşturulan nesnelere bağlı çalışır, bu yüzden nesneye ait özelliklerle işlem yapar ve bir nesne üzerinden çağrılır. Hiç nesne oluşturmadan doğrudan sınıf adı üzerinden çağrılmaları mantıklı değildir.
* Class method, fonksiyonun üstüne `@classmethod` dekoratörü eklenerek tanımlanır ve ilk parametre olarak self yerine sınıfın kendisini temsil eden cls parametresini otomatik alır.
* Class metotlar nesneye değil doğrudan sınıfın kendisine bağlıdır, bu nedenle sınıftan henüz hiç nesne üretilmemiş olsa bile sınıf adı üzerinden çağrılabilir.
* Class metotların en yaygın kullanım alanı alternatif yapıcı metot (constructor) olarak kullanılmalarıdır.
* Static method, fonksiyonun üstüne `@staticmethod` dekoratörü eklenerek tanımlanır.
* Static metotlar ilk parametre olarak ne self ne de cls alır. Sınıfın kendisinden ve sınıf değişkenlerinden bağımsız, yalnızca programcının istediği parametreleri alan (veya hiç parametre almayan) daha genel yardımcı fonksiyonlar gibi çalışır.
```python
class Calisan:
    zam_orani = 1.1       
    personel_sayisi = 0   
    
    def __init__(self, isim, maas):
        self.isim = isim  # instance variable (her nesneye ozel)
        self.maas = maas
        Calisan.personel_sayisi += 1 # self degil sinif adiyla artirdik ki herkes icin ortak artsin
    # instance method 
    def bilgi_ver(self):
        return f"{self.isim} - {self.maas} TL"

    # class method
    @classmethod
    def sayi_soyle(cls):
        return cls.personel_sayisi

    # class methodun alternatif constructor olarak kullanimi
    @classmethod
    def stringden_olustur(cls, veri):
        isim, maas = veri.split("-")
        return cls(isim, int(maas)) # parcalayip yeni nesne donduruyor

    # static method
    @staticmethod
    def yillik_maas(aylik):
        return aylik * 12

# hic nesne uretmeden class method cagirabiliriz
print(Calisan.sayi_soyle()) # Çıktı: 0
c1 = Calisan("Ali", 5000)
c2 = Calisan.stringden_olustur("Ayse-6000") # alternatif constructor ile nesne urettik
print(Calisan.sayi_soyle()) # Çıktı: 2
print(c1.bilgi_ver())       # Çıktı: Ali - 5000 TL (instance method nesne uzerinden cagirilir)
print(c1.__dict__)          # Çıktı: {'isim': 'Ali', 'maas': 5000} (zam_orani burada yok, siniftan aliyor)
# nesne uzerinden degistirirsek sadece o nesneye yeni ozellik eklenir, digerleri etkilenmez
c1.zam_orani = 1.2
print(c1.zam_orani, c2.zam_orani) # Çıktı: 1.2 1.1
# sinif uzerinden degistirirsek ortak deger guncellenir
Calisan.zam_orani = 1.3
print(c1.zam_orani, c2.zam_orani) # Çıktı: 1.2 1.3 (c1 kendi ozelligine sahip oldugu icin degismedi)
# static method kullanimi
print(Calisan.yillik_maas(5000))  # Çıktı: 60000
```

**Kalıtım**
* Bir üst sınıftan yeni alt sınıflar türetilerek, üst sınıfa ait tüm özelliklerin ve metotların alt sınıflara miras olarak aktarılmasıdır. Böylece ortak özellikleri her sınıfta baştan yazmaya gerek kalmaz.
* Kalıtım yaparken alt sınıf adının yanına parantez açılır ve miras alınacak üst sınıfın adı parantez içine yazılır (class AltSinif(UstSinif):). Alt sınıfın içine hiçbir şey yazılmasa bile (pass ile bırakılsa bile) üst sınıfın tüm özelliklerine ve metotlarına sahip olur.
* Alt sınıftan üretilen bir nesne üzerinden bir özelliğe veya metoda erişilmek istendiğinde Python önce alt sınıfın kendisine bakar; orada bulamazsa miras aldığı üst sınıfa gider.
* Üst sınıftan miras alınan bir sınıf değişkeni veya metot, alt sınıfta aynı isimle yeniden tanımlanarak güncellenebilir. Bu işleme üzerine yazma (override) denir ve alt sınıftaki nesneler artık üst sınıftakini değil kendi sınıfındaki yeni halini kullanır.
* Alt sınıfa üst sınıfta olmayan yeni bir özellik eklemek için `__init__` fonksiyonu alt sınıfta yeniden tanımlanır. Üst sınıfta zaten bulunan ortak özellikleri tekrar tekrar yazmak yerine `super().__init__(...)` kullanılarak bu parametreler üst sınıfa gönderilir, sadece yeni eklenen özellikler alt sınıfta tanımlanır.
* Alt sınıflar, üst sınıftan miras aldıkları metotların yanında sadece kendilerine özgü yeni metotlar da barındırabilir.
* Alt sınıfların `__init__` metodunda isteğe bağlı bir liste parametresi alınacaksa varsayılan değer olarak `None` verilip içeride kontrol edilmesi (eğer `None` ise boş liste `[]` atanması) hem nesne oluşturulurken doğrudan liste gönderilmesine hem de sonradan ekleme yapılmasına olanak tanır.
* Bir sınıfın nesneleri, başka bir sınıfın içindeki bir listede tutulabilir ve döngüyle gezilerek her bir nesnenin kendi metotları çağrılabilir.
* `isinstance(nesne, Sinif)` fonksiyonu, verilen nesnenin belirtilen sınıftan üretilip üretilmediğini kontrol eder ve True ya da False döndürür.
* `issubclass(AltSinif, UstSinif)` fonksiyonu, ilk yazılan sınıfın ikinci yazılan sınıftan miras alıp almadığını (alt sınıfı olup olmadığını) kontrol eder ve True ya da False döndürür.

```python
class Calisan:
    zam_orani = 1.1

    def __init__(self, isim, maas):
        self.isim = isim
        self.maas = maas

    def bilgileri_goster(self):
        return f"Ad: {self.isim}, Maas: {self.maas}"

# Calisan sinifindan miras alan alt sinif
class Yazilimci(Calisan):
    zam_orani = 1.2 # ust siniftaki zam oranini ezdik (override)

    def __init__(self, isim, maas, dil):
        super().__init__(isim, maas) # ortak ozellikleri ust sinifa gonderdik
        self.dil = dil               # sadece yazilimciya ozel yeni ozellik

    def bilgileri_goster(self): # metodu override edip dili de ekledik
        return f"Ad: {self.isim}, Maas: {self.maas}, Dil: {self.dil}"

# yine Calisan'dan miras alan baska bir alt sinif
class Yonetici(Calisan):
    def __init__(self, isim, maas, calisanlar=None):
        super().__init__(isim, maas)
        if calisanlar is None:
            self.calisanlar = [] # liste verilmezse bos baslasin
        else:
            self.calisanlar = calisanlar

    def calisan_ekle(self, calisan):
        if calisan not in self.calisanlar:
            self.calisanlar.append(calisan)

    def calisan_sil(self, calisan):
        if calisan in self.calisanlar:
            self.calisanlar.remove(calisan)

    def calisanlari_goster(self):
        for c in self.calisanlar:
            print(c.bilgileri_goster())

c1 = Calisan("Ali", 5000)
y1 = Yazilimci("Ayse", 7000, "Python")
yonetici1 = Yonetici("Metin", 10000) # basta liste vermedik bos basladi

yonetici1.calisan_ekle(c1)
yonetici1.calisan_ekle(y1)
yonetici1.calisanlari_goster()
# Çıktı:
# Ad: Ali, Maas: 5000
# Ad: Ayse, Maas: 7000, Dil: Python

yonetici1.calisan_sil(c1) # Aliyi listeden cikardik
print(y1.zam_orani)       # Çıktı: 1.2 

# isinstance ve issubclass 
print(isinstance(yonetici1, Calisan))  # Çıktı: True 
print(isinstance(y1, Yonetici))        # Çıktı: False 
print(issubclass(Yazilimci, Calisan))  # Çıktı: True 
print(issubclass(Calisan, Yazilimci))  # Çıktı: False 
```
